# Projeto Integrador: Lógica e Programação em Python

## 📝 Descrição
Este repositório contém o conjunto de Microatividades e o Trabalho Prático Final da disciplina **DGT2817**. O foco do projeto é demonstrar o domínio da linguagem Python, utilizando estruturas de controlo de fluxo, laços de repetição, modularização através de funções e tratamento de erros.

## 🚀 Tecnologias Utilizadas
- **Linguagem:** Python 3.10+
- **IDE Recomendada:** Visual Studio Code (VS Code)
- **Controlo de Versão:** Git & GitHub

## 📂 Estrutura do Projeto
O projeto está organizado nos seguintes ficheiros:

- `estruturas_condicao1.py`: Demonstração básica de `if` e `else` (Clima).
- `estruturas_condicao2.py`: Uso de `if`, `elif` e `else` (Níveis de Experiência).
- `estruturas_repeticao1.py`: Implementação de laço `while` com validação de saída.
- `estruturas_repeticao2.py`: Uso de laço `for` com strings e `range()`.
- `funcoes1.py`: Declaração e invocação de funções simples.
- `funcoes2.py`: Funções com parâmetros e normalização de strings.
- `calculadora.py`: Trabalho prático final integrando todos os conceitos.

1. Certifique-se de ter o Python instalado.
